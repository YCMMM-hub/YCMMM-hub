## Free browser tools

- [Open Microsoft Publisher (.pub) files without Publisher](https://ycmmm-hub.github.io/pubrescue/): convert .pub to PDF locally in your browser
- [Open and convert XPS / OXPS files to PDF](https://ycmmm-hub.github.io/xpsrescue/): free XPS viewer and converter, nothing uploaded
- [Free CHM viewer and CHM to PDF converter](https://ycmmm-hub.github.io/chmrescue/): read .chm help files in Chrome, offline
- [Calculadora de finiquito (España)](https://ycmmm-hub.github.io/finiquito/): calcula y comprueba tu finiquito antes de firmar
